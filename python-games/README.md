# 简易计算器

## 一、项目背景

我是计算机专业大一新生，刚开始学习 Python。为了练习函数、循环、条件判断和异常处理，也为了有一个自己的小项目传到 GitHub，我写了这个命令行计算器。

它不追求复杂，重点是让我理解：一个程序怎么从“用户输入”走到“计算结果”，以及怎么处理用户输错的情况。

## 二、项目功能

- 支持加法、减法、乘法、除法
- 支持次方运算，例如 2 的 10 次方
- 支持开方运算，例如 9 开方等于 3
- 支持连续使用，算完一次可以继续算
- 有防错处理：
  - 除以 0 会提示“不能除以 0”
  - 负数开方会提示“负数不能开平方”
  - 输入非数字会提示“请输入数字”
  - 菜单输入无效会提示重新输入
- 输入 7 退出程序

## 三、技术方案

- 编程语言：Python 3.13
- 开发工具：IDLE
- 使用模块：`math`，用于开方运算
- 程序结构：
  - 每个运算单独写成一个函数，例如 `add()`、`subtract()`、`multiply()`、`divide()`、`power()`、`sqrt()`
  - 主函数 `calculator()` 负责显示菜单、读取用户选择、调用对应函数
  - 用 `while True` 实现循环菜单，直到用户选择退出
  - 用 `try / except` 捕获输入错误，防止程序崩溃
  - 除法函数中判断分母是否为 0
  - 开方函数中判断数字是否为负数
